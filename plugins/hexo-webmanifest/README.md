# hexo-webmanifest

A hexo plugin to generate 'Web Application Manifest' json files and insert `<link>` tag to HTML.

## Feature

- Generate `site.webmanifest` from your config.
- Insert a `<link>` tag to reference the `site.webmanifest` in HTML.

## Install

[![NPM Version](https://img.shields.io/npm/v/hexo-webmanifest?logo=npm)](https://www.npmjs.com/package/hexo-webmanifest)
[![node-lts](https://img.shields.io/node/v-lts/hexo-webmanifest?logo=nodedotjs)](https://nodejs.org/about/previous-releases#release-schedule)

```bash
pnpm add hexo-webmanifest

# npm i hexo-webmanifest
```

## Configuration

### Example Configuration

#### General

```yaml
# _config.yml

hexo_webmanifest:
  enable: true
  manifest_dest_path: "site.webmanifest" # relative to `public/` dir

  enable_generate_manifest: true

  manifest_fieldMap: # mapping `_config.yml` to `webmanifest`.
    name: "title" # set `webmanifest.name` from `_config.title`.
    description: "description"
    start_url: "url"
    lang: "language"

  manifest_override: # overriding `webmanifest` key-value by your own.
    display: "standalone"
    short_name: "myname"
    theme_color: "#0e83cd"
    background_color: "black"
    related_applications:
      - platform: "web"
        url: "https://example.com/hexo-webmanifest/"
    icons:
      - src: "/icon/favicon-16x16.png"
        sizes: "16x16"
        type: "image/png"
      - src: "/icon/favicon-512x512.png"
        sizes: "512x512"
        type: "image/png"

  enable_inject_tag_link: true
```

#### Inject `<link>` tag **only**, don't generate webmanifest

```yaml
# _config.yml

hexo_webmanifest:
  enable: true
  manifest_dest_path: "site.webmanifest" # required by injecting tag
  enable_generate_manifest: false # disable manifest generating

  enable_inject_tag_link: true
```

## Options

---

### Enable or disable this plugin

| option key | value type | default value | note                                                                                                                      |
| ---------- | ---------- | ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `enable`   | `boolean`  | `true`        | Control whether to enable [`hexo-webmanifest`](https://github.com/uiolee/hexo-plugin/tree/main/plugins/hexo-webmanifest). |

---

### Generate `webmanifest` file

| option key                 | value type                                                | default value                                                     | note                                                                                                                                                                                            |
| -------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `manifest_dest_path`       | `string`                                                  | `site.webmanifest`                                                | Specify the path of your "webmanifest" file destination. (relative to `public/` dir)                                                                                                            |
| `enable_generate_manifest` | `boolean`                                                 | `true`                                                            | Specify whether to generate manifest                                                                                                                                                            |
| `manifest_basic`           | `object`. (see valid keys in [MDN][MDN_MANIFEST_REF])     | see details in [./src/default_config.ts](./src/default_config.ts) | It will be overrode by the content generated by `manifest_fieldMap` mapping and the content of `manifest_override`                                                                              |
| `manifest_fieldMap`        | `object extends Record<keyof MANIFEST, keyof CONFIG_YML>` | see details in [./src/default_config.ts](./src/default_config.ts) | Specify mapping key from `_config.yml` to "webmanifest". Generate manifest from your `_config.yml`.                                                                                             |
| `manifest_override`        | `object`. (see valid keys in [MDN][MDN_MANIFEST_REF])     | `{}`                                                              | This option have highest priority, which means it could override the manifest content which come from `manifest_basic` and the manifest content which generated by `manifest_fieldMap` mapping. |

---

### Insert a `<link>` tag for `webmanifest`

> Some themes likes next have the same feature, you may not to use this if you have enabled this feature in themes.

| option key               | value type | default value      | note                                                                                 |
| ------------------------ | ---------- | ------------------ | ------------------------------------------------------------------------------------ |
| `manifest_dest_path`     | `string`   | `site.webmanifest` | Specify the path of your "webmanifest" file destination. (relative to `public/` dir) |
| `enable_inject_tag_link` | `boolean`  | `true`             | Specify whether to inject a `<link>` to `<head>` of HTML                             |
